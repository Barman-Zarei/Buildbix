# Security policy

BUILDBIX is an **early-stage prototype**. It runs user-supplied project code in build sandboxes and talks to third-party APIs; do **not**
expose it to the public internet without hardening (see `docs/SECURITY.md`, "Known gaps").

## Reporting a vulnerability
Please report privately, using either:
- GitHub's **"Report a vulnerability"** button (Security tab of this repository > Advisories), or
- email **buildbix.security@gmail.com**.

Do **not** open a public issue for security problems. Include steps to reproduce and the affected version/commit.
Reports are acknowledged on a best-effort basis (this is a small volunteer project) and reporters are credited if they wish.

## Supported versions
Only the latest commit on the default branch is supported.
